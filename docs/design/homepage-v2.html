One-turn messages: draft → finalize

A composed message is a draft until sent. A streamed reply is marked as finalizing while chunks arrive. No multi-editing in v1 — finalize = send.

draft · visitor We need a returns-management tool for our marketplace — about 3 months, mid budget.
senddiscard
streaming · agent Got it — a returns-management tool…
finalizing
final · agent Great starting point. To collect the brief, could you tell me: (1) who the users are, (2) the core features, (3) the timeline?
copyfinalized
Copy action copies the message text to the clipboard (navigator.clipboard), with "copied" confirmation state.
